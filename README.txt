AUTOSAIMAN.KZ — четыре интерактивных UX/UI-прототипа

Откройте index.html, чтобы выбрать дизайн.
Варианты 01–03 автономны, изображения встроены внутрь. Вариант 04 использует реальные логотипы из папки assets/brands и сценарии из AUTOSAIMAN_04_APP.js — сохраняйте их рядом с HTML-файлом.
Внутри прототипов ссылки переключения между стилями работают, если файлы расположены в одной папке.
Вариант 04: выберите 3D-логотип марки — откроется каталог совместимых товаров. Работают живой поиск по названию, артикулу и VIN, выбор автомобиля, фильтры, сортировка, карточки товаров, избранное, корзина, оформление заказа и информационные страницы.
Демонстрационные данные, цены и тестовые формы. Платежей и реальных заказов нет.
Для публикации загрузите содержимое папки на статический хостинг.
